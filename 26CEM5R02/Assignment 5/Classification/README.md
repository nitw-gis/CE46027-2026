# Wine Quality Classification Using Artificial Neural Network (ANN)

## 1. Project Overview

This project was completed as part of an AI/ML classification
assignment. The objective is to perform data preprocessing,
feature-space visualization and multiclass classification of wine
quality using an Artificial Neural Network (ANN). The experiments
examine how ANN architecture and hyperparameters affect classification
and computational performance.

The updated ANN workflow includes:

-   Dataset inspection and duplicate removal.
-   Numerical feature standardization.
-   One-hot encoding of categorical data.
-   2D t-SNE feature-space visualization.
-   ANN classification using a Multi-Layer Perceptron.
-   Eight hidden-layer configurations.
-   Three activation functions: ReLU, Tanh and Logistic.
-   Three learning rates.
-   Accuracy, weighted Precision, weighted Recall and weighted F1-score
    evaluation.
-   Confusion matrix and classification report for the selected model.
-   Training and prediction time measurement.
-   CPU and memory resource monitoring.
-   Parameter comparison plots and a hyperparameter comparison heatmap.

The ANN implementation is an additional classification approach; it is
distinct from the earlier SVM and Decision Tree experiments described in
the previous assignment README.

## 5. Data Preprocessing

### Duplicate Removal

Duplicate observations are identified and removed before the train,
validation and test split.

### Train, Validation and Test Split

The ANN workflow first separates 20% of the data as the final test set.
The remaining 80% is split again, with 25% of that portion used for
validation.

This produces approximately:

-   60% training data.
-   20% validation data.
-   20% testing data.

The split uses `random_state=42` and stratification based on the
`quality` target. The 72 ANN configurations are compared using
validation metrics. The held-out test data is used only after the
selected configuration has been chosen.

### Numerical Feature Scaling

Numerical features are standardized using `StandardScaler`.

The equation is:

$$
z = \frac{x-\mu}{\sigma}
$$

where: - `x` is the original feature value. - `μ` is the feature mean. -
`σ` is the feature standard deviation.

### Categorical Encoding

The categorical `type` feature is converted into numerical form using
One-Hot Encoding with `handle_unknown="ignore"`.

The preprocessing steps are implemented using scikit-learn's
`ColumnTransformer` and `Pipeline`.

## 7. Artificial Neural Network Classification

The ANN classifier is implemented using the `MLPClassifier` class from
scikit-learn.

A Multi-Layer Perceptron contains an input layer, one or more hidden
layers and an output layer. The network learns patterns in the input
data by adjusting its weights and biases during training.

### 7.1 Hidden-Layer Configurations

The number of hidden layers is varied from 1 to 8. Each hidden layer
contains 64 neurons.

The architectures are:

-   1 hidden layer: `(64,)`
-   2 hidden layers: `(64, 64)`
-   3 hidden layers: three layers containing 64 neurons each
-   4 hidden layers: four layers containing 64 neurons each
-   5 hidden layers: five layers containing 64 neurons each
-   6 hidden layers: six layers containing 64 neurons each
-   7 hidden layers: seven layers containing 64 neurons each
-   8 hidden layers: eight layers containing 64 neurons each

### 7.2 Activation Functions

Three activation functions are tested:

-   **ReLU (`relu`)** -- Rectified Linear Unit.
-   **Tanh (`tanh`)** -- Hyperbolic tangent.
-   **Logistic (`logistic`)** -- Sigmoid activation function.

### 7.3 Learning Rates

The following initial learning rates are evaluated:

-   `0.0005`
-   `0.005`
-   `0.05`

The learning rate controls the step size used to update the network
weights during training.

### 7.4 Experiment Combinations

The experiment evaluates:

-   8 hidden-layer configurations.
-   3 activation functions.
-   3 learning rates.

The total number of ANN configurations is:

$$
8 \times 3 \times 3 = 72
$$

The model uses the Adam optimizer, a maximum of 300 iterations,
`tol=1e-4` and `random_state=42`. Early stopping is disabled in the
experiment script.

## 8. Evaluation Metrics

The ANN classification model is evaluated using:

-   Accuracy.
-   Weighted Precision.
-   Weighted Recall.
-   Weighted F1-score.
-   Confusion Matrix.
-   Classification Report.

### Accuracy

Accuracy is the proportion of all predictions that are correctly
classified.

### Precision

Precision measures how many samples predicted as a particular class
actually belong to that class. The script reports weighted precision.

### Recall

Recall measures how many actual samples of a class are correctly
identified. The script reports weighted recall.

### F1-score

F1-score is the harmonic mean of precision and recall:

$$
F1 = 2 \times \frac{Precision \times Recall}{Precision + Recall}
$$

Weighted averaging is used for Precision, Recall and F1-score so that
each class contributes according to its support (number of actual
samples).

### Confusion Matrix and Classification Report

The confusion matrix summarizes correct and incorrect predictions by
actual and predicted class. The classification report provides
class-wise precision, recall, F1-score and support.

## 9. Model Selection and Final Test Evaluation

All 72 configurations are compared using validation weighted F1-score.
The configuration with the highest validation F1-score is selected, with
validation accuracy used as a secondary sorting criterion.

The selected architecture is then retrained using the combined training
and validation data. It is evaluated once on the separate held-out test
set.

The final test evaluation reports:

-   Accuracy.
-   Weighted Precision.
-   Weighted Recall.
-   Weighted F1-score.
-   Test prediction time.

This separates hyperparameter selection from final test evaluation.

## 10. Computational Resource Analysis

The ANN experiments record computational measurements for all 72
configurations:

-   Training time.
-   Prediction time.
-   CPU process time.
-   CPU utilization snapshot.
-   Memory before training.
-   Memory after training.
-   Memory change.
-   Number of training iterations.
-   Whether the model reached the maximum iteration count.

Training and prediction time are measured using Python's
`time.perf_counter()`. CPU process time is measured using
`time.process_time()`. Process memory is monitored using `psutil`.

Memory change is a before-and-after difference in process memory, not
peak memory usage. CPU process time and wall-clock time measure
different quantities and may differ, particularly when computation uses
multiple CPU threads. The CPU utilization value is a process utilization
snapshot and should not be interpreted as a continuous average over the
entire experiment.
